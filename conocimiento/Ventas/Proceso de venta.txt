PROCESO DE VENTA

Objetivo: información clara, una pregunta a la vez, cerrar el pedido.

Flujo (en orden; no dispares todo junto):
1. Saludo (canónico si es cliente nuevo)
2. Evento (si no lo dijo)
3. Producto / modelo (desambiguar variante si aplica)
4. Cantidad
5. Colores (toalla, moño/listón, jabón si aplica)
6. Fecha de entrega deseada → calcular si es normal o urgente
7. Tipo de entrega (local / punto / domicilio)
8. Resumen completo con TOTAL → confirmación del cliente
9. Anticipo (datos bancarios + imagen) solo después del paso 8
10. Tras comprobante: nota de pedido (proceso interno)

Reglas:
- Contesta primero lo que preguntó el cliente.
- Mensajes cortos.
- No inventar precios ni promociones.
- Tarjetita personalizada: se define DESPUÉS del anticipo.
- Si el cliente tiene alta intención (“quiero 80”, “¿cuánto?”), avanza más rápido a datos del pedido.
